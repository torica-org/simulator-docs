# シングルトンパターン

`GameManager`や`UIManager`で用いている手法です．  
`MonoBehaviour`を継承しながら，ゲームのシーンがロードされても破棄されない`static`なインスタンスとなります（`DontDestroyOnLoad`というヒエラルキーでの表示がそれを示します）．  

`static`なインスタンス経由なので，プロジェクト内のどこからでもアクセスできます．

例)
```csharp
GameManager.instance.game.Status = GameParameters.Status.Flight;
// 「GameManagerクラスの」.「instanceへのアクセス」.「game(GameParametersのインスタンス)へのアクセス」.「Statusへのアクセス」
```

## 作り方
例) GameManager
```csharp
public static GameManager instance = null;
public bool FirstLoad = false;

private void Awake()
{
    if (instance == null)
    {
        instance = this;
        FirstLoad = true;
        DontDestroyOnLoad(this.gameObject);
    }
    else
    {
        FirstLoad = false;
        Destroy(this.gameObject);
    }
}
```
