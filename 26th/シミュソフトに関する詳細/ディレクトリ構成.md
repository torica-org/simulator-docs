# ディレクトリ構成
`src/Assets/Script/`配下
- `Aircraft`：飛行機のシミュレーションやゲームオブジェクトに対する処理スクリプト
- `Button`：UIのボタンにアタッチされたスクリプト
- `Camera`：`Camera`やVR関連のスクリプト
- `DataIO`：CSVファイルやその他ファイルの入出力を管理するスクリプト
- `Dev`：一時的な開発時検証用スクリプト
- `Game`：ゲームの進行に関わるスクリプト
- `Graph`：グラフの描写に関するスクリプト
- `HUD`：フライト時に画面周囲に表示される情報の表示用スクリプト
  - 分類として正しくありませんが，`Sprashdown.cs`が含まれています．
- `Other`：飛行禁止区域に関するスクリプト（もっといいディレクトリあるでしょ...）
- `Serial`：シリアル通信に関するスクリプト
- `Settings`：パラメーター調整用のUI用スクリプト（無法地帯）
- `SystemController`：ゲームシステムに関係する補助スクリプト
- `Title`：バージョン表示用スクリプト
- `UI`：UIに関するスクリプト
  - `UIClasses`：UIを数行のスクリプトで生成できるようにするクラス郡
